# Dataarkitektur-artefakt

Formaal: formelt datakatalog over de datapunkter ArchAI henter fra
integrationer og selv beregner.

Verifikationsbaseline:

- kodegennemgang i `src/integrations/`, `src/lib/analysis-orchestrator.ts`,
  `src/lib/compliance-layer1.ts`, `src/lib/project-update-builder.ts`,
  `src/lib/rule-engine/*`
- live audit `2026-06-05` mod `Hasselvej 48, 2830 Virum`

Statusnoegle:

- `Live` = verificeret mod upstream i audit
- `Delvis` = upstream svarede, men ikke alle felter eller lag er bekraeftet
- `Kode` = koden findes og er boundary-valideret, men ikke live-verificeret i auditen
- `Blokeret` = kunne ikke verificeres i nuvaerende miljoe

## Governance-observationer

| Emne               | Observation                                                 | Betydning                                                                       |
| ------------------ | ----------------------------------------------------------- | ------------------------------------------------------------------------------- |
| `adgangsadresseid` | mangler stadig ofte i det foerste UI-state                  | Risiko for at downstream-opslag starter paa et svagere grundlag end noedvendigt |
| Tinglysning        | ikke live-verificerbar i nuvaerende miljoe                  | Juridiske bindinger maa behandles som utilstraekkeligt daekkede                 |
| EMOData            | credentials mangler                                         | Energispor kan ikke kaldes robust produktklart                                  |
| DK-Jord            | olietank- og omraadeklassificeringslag gav `400` i audit    | Forureningsbilledet er delvist usikkert                                         |
| FBB                | adresse-fallback gav 0 hit                                  | "Ingen traef" maa ikke laeses som "ingen bevaringsrisiko"                       |
| DHM                | `northOrientation` er haardkodet til `"S"`                  | Feltet maa ikke bruges som beslutningsstotte foer rettelse                      |
| Arealdata          | `fortidsminde` og `fortidsmindeBuffer` er eksplicit ukendte | Kulturarvsrisiko er underdaekket                                                |

## Anbefalet brug af artefaktet

Dette dokument boer bruges som reference, naar et datapunkt skal:

- flyttes til typed SQL-kolonne
- vises som beslutningssignal i UI
- bruges som input til regelmotor eller AI-forklaring
- vurderes for live-driftsmodenhed, governance eller kvalitetsovervaagning

Det vigtigste skel i ArchAI er stadig:

- raa registerdata
- typed persistensfelter
- afledte beslutningsfelter
- AI-genererede forklaringsfelter

ArchAI er due-diligence software. Derfor maa forklaringsfelter aldrig forveksles
med compliance-sandhed.
